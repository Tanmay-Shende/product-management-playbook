# Agent Instructions

This repository contains vendor-neutral product management skills.

When using a skill:
1. Identify the smallest set of relevant skills under `Skills/`.
2. Read the relevant `SKILL.md`.
3. Follow the procedure and output requirements.
4. Distinguish facts, assumptions, hypotheses, and recommendations.
5. Never invent material facts, financial values, customer evidence, or market data.
6. Surface missing inputs and uncertainty.
7. Optimize for the user's decision or outcome, not document length.

The skills are intentionally generic and should work across Claude, ChatGPT, Gemini, Codex, Copilot, and other AI agents. Do not rely on vendor-specific commands, APIs, or hidden capabilities.
