# Product Management Skills

A compact, vendor-neutral library of reusable product management skills for humans and AI agents.

## Structure

All skills live directly under `Skills/`. Each skill has a `SKILL.md` for execution and a `README.md` for usage, examples, and context.

## AI compatibility

The repository is designed to work with Claude, ChatGPT, Gemini, Codex, Copilot, and other AI agents. `AGENTS.md` contains the generic agent instructions. No skill depends on a vendor-specific command or runtime.

## Typical workflow

`customer-problem-definition → customer-discovery → product-strategy → prioritization → business-case → product-requirements → product-roadmap → product-metrics`
