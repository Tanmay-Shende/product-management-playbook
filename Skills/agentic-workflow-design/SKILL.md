# Agentic Workflow Design

## Purpose
Design safe, bounded workflows where software agents can plan, decide, and act.

## When to use
When moving from AI assistance toward delegated execution.

## Procedure
1. Define the user goal.
2. Map workflow steps.
3. Identify agent actions and tools.
4. Define permissions and limits.
5. Define identity and authentication.
6. Define human approval points.
7. Define auditability and observability.
8. Define failure, reversal, and dispute handling.
9. Start with a bounded workflow.

## Output
Agent role, workflow, tools, permissions, policies, approvals, identity, audit trail, failure handling, and rollout plan.

## Guardrails
The design must answer what the agent can do, under whose authority, within which policy, and what happens when it is wrong.
