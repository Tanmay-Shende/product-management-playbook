# Customer Problem Definition

## Purpose
Turn a broad issue into a specific, testable customer problem.

## When to use
When teams jump to solutions before agreeing on the actual problem.

## Procedure
1. Define who experiences the problem.
2. Describe the context and trigger.
3. Separate symptoms from root causes.
4. Quantify consequences where possible.
5. State the desired customer outcome.
6. Write a concise problem statement.
7. List unknowns.

## Output
Customer, context, problem statement, evidence, consequences, desired outcome, and open questions.

## Guardrails
Do not embed the solution in the problem statement.
