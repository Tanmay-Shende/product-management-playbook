# Using this skill

This folder contains a reusable product management skill for humans and AI agents.

## How to use
Provide the decision or outcome, relevant context, evidence, constraints, audience, and desired format. Then ask the agent to read `SKILL.md`, follow its procedure, separate facts from assumptions, and flag missing inputs.

## Example prompt
"Use this skill for the following situation: [describe the problem]. Here is the available context: [context]. Produce the required output for [audience]."

## Good output
A useful result should be concise, evidence-aware, explicit about assumptions, and focused on the decision or customer/business outcome.

## AI-agent compatibility
No vendor-specific command or runtime is required. The skill is designed to work with any agent that can read Markdown files.
