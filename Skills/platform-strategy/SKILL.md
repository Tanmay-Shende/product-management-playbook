# Platform Strategy

## Purpose
Determine which reusable capabilities should become shared platform infrastructure.

## When to use
When multiple products need similar capabilities or platform investment is under consideration.

## Procedure
1. Map recurring needs.
2. Identify shared primitives.
3. Define platform boundaries.
4. Identify consumers.
5. Define contracts and interfaces.
6. Set governance and service levels.
7. Measure adoption and leverage.
8. Separate platform work from product work.

## Output
Platform thesis, consumers, shared capabilities, boundaries, contracts, governance, metrics, and roadmap.
