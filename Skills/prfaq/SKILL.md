# PRFAQ / Press Release

## Purpose
Define a product from the customer's perspective before committing to implementation.

## When to use
Early product definition or difficult alignment discussions.

## Procedure
1. Write a future-dated press release.
2. Lead with customer value.
3. Describe the problem and outcome.
4. Explain what is new.
5. Write FAQs covering scope, differentiation, economics, rollout, and risks.
6. List unresolved questions.

## Output
Headline, customer problem, solution, benefits, how it works, availability, FAQ, and open questions.
