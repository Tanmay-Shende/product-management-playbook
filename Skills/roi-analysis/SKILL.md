# ROI Analysis

## Purpose
Compare investment with incremental economic value.

## When to use
Product, platform, operational, or technology investments.

## Procedure
1. Define the counterfactual.
2. Estimate incremental benefits.
3. Estimate one-time and recurring costs.
4. Model timing.
5. Calculate ROI and, where useful, payback or NPV.
6. Run sensitivities.
7. State confidence.

## Output
Economic model, ROI, payback or NPV where useful, sensitivities, and recommendation.

## Guardrails
Define the period and denominator for every ROI claim.
