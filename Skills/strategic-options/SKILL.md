# Strategic Options

## Purpose
Frame materially different choices and make tradeoffs explicit.

## When to use
High-impact decisions with multiple plausible paths.

## Procedure
1. State the decision.
2. Generate 3 to 5 genuinely different options.
3. Assess upside and downside.
4. Evaluate investment, risk, time to value, and reversibility.
5. State what each option gives up.
6. Recommend an option or sequence.

## Output
Options, comparison, tradeoffs, recommendation, and conditions for success.
